# Trampakí — Pitch Deck Executivo Interativo

Apresentação interativa executiva e técnica do **Trampakí** (marketplace sob demanda de turnos e diárias operacionais com match geolocalizado e duplo aceite).

## 🚀 Como Visualizar

- **GitHub Pages:** Ative o GitHub Pages em **Settings > Pages > Branch: `main` / root** para rodar o pitch diretamente pelo navegador.
- **Localmente:**
  ```bash
  npm install
  npm run dev
  ```
  Ou abra o arquivo `index.html` diretamente em qualquer navegador moderno.

## 📂 Estrutura do Repositório

- `index.html`: Apresentação completa e auto-contida (10 slides com dual-screen para banca e teleprompter integrado).
- `assets/aistudio/`: Telas e capturas reais do app Trampakí (Slide 05: Jornada do Candidato e Estabelecimento).
- `package.json` & `vite.config.ts`: Configuração do servidor de desenvolvimento local.
- `tsconfig.json`: Configuração do TypeScript.
